## 字段定义

| 字段 | 含义与处理 |
|---|---|
| `record_type` | `indicator`表示一条指标目录记录；`function`表示通用函数说明。 |
| `market` | 直接取所在第11章子节标题，使用“股票”“港股”等原目录名称；不由代码后缀推断。通用函数说明为空字符串。 |
| `section` | 原章节编号，如`11.1`、`11.2`；通用函数说明为`11`。 |
| `category` | 原表“路径”列，仅移除排版换行；不重组目录、不补分类。 |
| `name` | 原表“指标名称”列，仅移除排版换行，保留原有文字和字符间空格。 |
| `code` | 原表“指标代码”列，仅移除自动换行；保留大小写、点号和原始后缀。不是记录唯一键。 |
| `parameters` | 指标为原表第四列，保留原文和换行。空字符串表示原表该列为空，不能推定无需证券代码、参数可选或有默认值。函数说明记录保存p17说明段落，不转换成推测的参数模式。 |
| `pdf_pages` | 对应物理页号列表，从1开始；跨页目录行列出两页。不能当成印刷页号，本PDF正文印刷页号比物理页号少2。 |
| `raw_text` | 按路径、名称、代码、参数的列顺序保留各列原文和换行；跨页片段之间用两个换行分隔。不包含表格线，也不是页面阅读顺序的逐字坐标转录。函数说明记录保留说明段落原文。 |
| `source_rows` | 每个物理行片段的`pdf_page`与`bbox`。矩形采用PDF点坐标`[x0,y0,x1,y1]`，原点在页面左上角，供回查原表。 |
| `parse_status` | `extracted`表示已完成文本列映射；`review`预留给已发现而未能可靠解析的记录。该字段不表示当前接口验证通过。本次`review`记录为0。 |
| `notes` | 跨页拼接、代码自动换行及解析疑点说明；无说明时为空数组。 |

原文里的字母、数字与汉字之间的空格未统一改写。查询名称时需考虑这些源文空格；按代码查询可避免这一问题。

## 提取方法与覆盖审计

使用项目指定venv中的PyMuPDF读取文字与绘制对象，未改动原PDF。先探查p17-20的四列表格和跨页，再检查公司资料及各市场起始页。利用表格左侧竖线确定物理行片段，再取同一行的5条竖向边界分配4列；不同市场的列宽由各行边界读取，不套用统一横坐标。

p17-1427共识别14616个四列表格片段。其中34个是目录标题及表头，14582个是数据片段；数据片段包括14130个含码首片和452个跨页续片。续片全部位于下一物理页顶部、指标码列为空，且与上一页最后数据片段属于同一章节。按相同列拼接，最终形成452条跨页记录。未将示例重复计为指标，也未按代码去重。

逐片段审计确认14582个数据片段各自且仅归属一条记录。四列内容逐项回对拼接前片段，全部一致。p18-1427正文文本行均被表格片段覆盖，未分配的目录正文文本行为0。p17的表格外正文是第11章标题及函数说明，另以一条`function`记录收录说明段落。全部指标记录的市场、名称和路径均非空，参数的半角及全角括号计数均平衡。

另选21个物理页，用PDF行矩形独立裁取文本，与保存的列原文去空白后比较，未发现差异。页码为p19、20、28、29、419、421、422、524、525、662、680、794、825、1105、1200、1292、1354、1399、1400、1407、1427。

审计证明本次识别到的表格文本行已全部纳入。未逐页视觉审查或OCR截图，未验证PDF文本层与页面图像的每个字形一致，也未核验手册本身的业务正确性。p1-16为封面、总目录与操作向导，未发现可独立新增的指标目录文本行；向导截图中的文字不在本次OCR覆盖范围。索引不声称当前插件全部指标已经覆盖。

## 检索示例

在项目根目录使用ripgrep按原码定位。

```powershell
rg -n '"code":"ths_corp_cn_name_stock"' reference/ifind-Excel公式索引-20181218.jsonl
rg -n '"market":"债券".*hx_s_segment_' reference/ifind-Excel公式索引-20181218.jsonl
```

使用Python按市场、目录和名称查询，保留同码多条结果。

```python
import json
from pathlib import Path

path = Path("reference/ifind-Excel公式索引-20181218.jsonl")
with path.open(encoding="utf-8") as stream:
    for line in stream:
        row = json.loads(line)
        if row["market"] == "港股" and "公司资料" in row["category"]:
            print(row["name"], row["code"], row["parameters"], row["pdf_pages"])
```

精确检索时可用`row["code"] == "ths_np_stock"`；不要先把记录转成以代码为键的单值字典，否则会覆盖不同目录的原始条目。
