# 第三块 额外功能

这一层放「一件事一件事单独实现」的功能：绘图、报告。每个功能自己取数、自己加工、自己出成果，调用方只需要给少数几个参数。

加新功能时不要往第二块的取数逻辑里塞，也不要在 `cli.py` 里写编排——编排属于本层。

## 绘图

`chart.py`。一个模板一个函数，模板之间共享基础格式化与配色。

调用：`{"cmd":"draw","template":"kline_volume","data_path":"行情.csv","output":"图.png"}`

| 模板 | 画什么 | 主要参数 |
|---|---|---|
| `kline_volume` | K线 + 成交量 + 均线 | data_path、output |
| `kline_log_volume` | 同上，纵轴对数 | data_path、output |
| `close_mcap_events` | 双轴：左总市值、右前复权收盘价，可标注事件 | data_path、output、events |
| `close_line_keypoints` | 折线 + 高点低点标注，可标回撤 | data_path、output、keypoints、drawdown_threshold |

绘图只读已导出的行情 CSV，不自己取数。视觉规范统一在 `chart.py` 内固定：
纯白背景、不要底色、字号放大，便于打印后阅读。

新增一个模板：在 `chart.py` 里加一个函数并在模板分派里登记，参数保持少数几个，颜色与布局写死在模板里。

## 报告

两个文件分工，不要混：

| 文件 | 管什么 |
|---|---|
| `report.py` | 排版：把已取到的记录拼成 Markdown，做单位换算与小标题。不取数 |
| `report_command.py` | 编排：决定取哪些板块、铺几期、按什么口径，然后调排版与绘图并落盘 |

调用：`{"cmd":"report","code":"002796.SZ","output":"导出目录"}`

可选参数：`company`（省略则取工商信息里的证券简称）、`end_date`（数据截止交易日，默认今天）、
`chart_start`（行情图画图起点，默认 2016-01-01）、`events`（事件 CSV，有则标注）。

产出：一份 `公司-报告骨架-<时间戳>.md`、各板块 CSV、一张行情图 PNG。

报告口径属于本功能的业务规则，放在 `report_command.py` 里：

- 报告期列：最新期 + 去年同期 + 逐年年报，共 7 列。
- 营收结构一类只取年报与中报，不用三季报一季报。
- 分红取最近 7 个年度。
- 盈利预测取未来 3 个年度加历史 4 个年度。

要出港股或美股版报告时，在此新增一份编排函数，按代码后缀分派；不要改通用取数层。
