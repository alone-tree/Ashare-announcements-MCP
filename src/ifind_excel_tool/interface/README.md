# 第四块 AI 交互

这一层是调用的 AI 直接接触的东西：搜科目、看帮助、查证券代码、以及 `cli.py` 的命令分派。

目标只有一个：让调用的 AI 清楚知道能拿什么、怎么拿，并且不因为返回内容太多而看不完。

## 两个检索不要混

| 命令 | 搜什么 | 什么时候用 |
|---|---|---|
| `find` | 科目（指标、衍生科目、组合、批量公式、特殊能力） | 不知道某个数据的科目名叫什么 |
| `search` | 证券代码 | 知道公司名但不知道 iFinD 代码 |

`find` 搜「毛利率」拿科目；`search` 搜「贵州茅台」拿 `600519.SH`。两者不互相替代。

## 返回内容的三条约束

- 每页有上限。`find` 默认 10 条、最多 50 条，带 `total` 与 `has_more`，翻页用 `offset`。`search` 每页 10 条。
- 大结果落盘。行数超过阈值的取数结果自动写 CSV，返回里只留前 20 行并标 `truncated`，完整数据看 `export.path`。判断取到多少看 `rows`，不看 records 长度。
- 每条命中带用法。`find` 的每条结果都有 `call`（怎么调）、`returns`（会拿到什么形状）、`description`。看到就能直接调，不需要再查一次。

## 帮助

`help` 一页给三样东西：能取什么、从哪开始、几条硬规则。`packages` 列全部科目组合，
`package_info` 看某个组合的字段与参数，`help_indicators` 按市场或关键词列原始公式。

帮助里只写当前有效的事实，不写历史变更；返回结构保持稳定，字段不随意增减。

## 文件职责

| 文件 | 职责 |
|---|---|
| `search.py` | 科目检索：匹配与排序，别名优先展示 |
| `securities.py` | 证券代码检索：股票走东方财富，指数外汇查本地表 |
| `help.py` | 帮助：总览、组合清单、组合详情、公式清单 |
| `data/` | 检索用的指数总表与汇率表，`build_index_table.py` 从 xlsx 重新生成 |

检索排序只有本层关心，所以新增一种科目类型时，本层要给一个合理的展示顺序（`KIND_ORDER`），
否则命中会挤在一起。
