**来源链原则（2026-08-08 拍板；行情单源化 2026-08-09 定稿）**：不按数据源统一排优先级——**每个字段有自己的来源链**（字段为中心，数据源不是分析单位）：

- **价格 open/high/low/close（raw）：AK 新浪（单源，A/港/美三市场，全历史）**——2026-08-09 定稿：raw 是事实价格，新浪三市场全历史且稳定；EODHD（免费 1 年）、腾讯（仅 A 股 OHLC）退出行情链保留为知识；东财行情域限流不参与
- volume：新浪（三市场）
- amount：A/港=新浪；**美股=仅东财**（新浪无；东财限流则缺失标注，不跨源补）
- **hfq 后复权：A/港股 = 新浪、美股 = iFinD `107,OC`——单源无回退（2026-08-09 拍板：失败即失败不混源，避免不同源数据混杂；原 东财→新浪 链与 EODHD 因子转换恢复均停用）**；**hfq 只存 close，OHL 由因子 `F(t)=hfq_close/raw_close` 还原**（600519 还原误差 0.035% 实测；港股除权日新浪直返 OHL 本身失真 ~1.9%，close 可靠）
- 股本：iFinD（THS_DS/THS_BD，§8 方案）→ A股 新浪 outstanding_share / 港美股 yfinance（~10 年）
- 市值：**计算法**（股本 × 不复权收盘，逐日对齐），不做直接获取（2026-08-08 定稿，见 §7 结论 9）
- 北交所：**新浪 raw+hfq 均支持（2026-08-09 实测 bj920002 全历史）**
- 财报/指标/概况：东财 datacenter

**核心原则**：字段为中心、来源可插拔；前复权本地计算不依赖源；市值走计算法（股本 × 不复权收盘，不做直接获取）。

### 1.4 复权口径（2026-08-08 定稿；后复权单源化 + 只存 close 2026-08-09 修订）

- **除权价**：新浪单源直取，核心组一次打包（OHLC 四列）。
- **后复权价**：**只存收盘价 + 因子还原 OHL，单源无回退（2026-08-09 用户拍板：避免不同源数据混杂，失败就是失败）**——**基本口径 = 现金分红（价格复权），不用红利再投**（与主流行情工具一致、可交叉验证）；A/港股=新浪 hfq（akshare `stock_zh_a_daily`/`stock_hk_daily`）、美股=iFinD THS_DS `107,OC`（近 5 年，后缀用 THS_HQ `Interval:W` 探测 `.O`/`.N`，不猜后缀）；缓存 hfq 文件只存 `date+close`，逐日因子 `F(t)=hfq_close/raw_close`，`hfq_OHL = raw_OHL × F(t)`；源失败=缓存未更新提示重试，不跨源补缺。原"东财 hfq / iFinD CPS:3 / EODHD 因子转换"路径均停用。⚠️ iFinD `THS_HQ CPS:7` 与 `THS_DS 107` 差 26.4%（AAPL，比值 0.795 且漂移）= 不同复权方式（疑似红利再投），THS_HQ 只用于后缀探测。⚠️ **美股 hfq 覆盖边界（上游问题不修复）**：部分美股有效数据短于 5 年（COHR.N 实测仅 2023-02-23 起，更早 NaN 占位），有就接受、缺失范围标注。还原精度：600519 全历史误差 ≤0.035%；**港股除权日新浪直返 OHL 本身失真 ~1.9%**（2023-12-22 open 旧因子/close 新因子），close 可靠。实证：600519 iFinD↔新浪比值恒定 0.9965；0700.HK 比值漂移 1.049→1.085 不可混用。
- **前复权价**：**本地计算，不依赖源、不缓存**：`前复权(t) = 后复权(t) × (最新不复权收盘 / 最新后复权收盘)`，因子取同一交易日，随分红自动更新。
- 缓存只存 raw + hfq 两个文件（静态历史永不过期）。
- **成交量/成交额不做复权处理**（2026-08-08 实测：新浪港股 raw/qfq/hfq 三档下 volume/amount 完全相同）——复权只作用于价格。
- 周/月线：由日线本地聚合（open=首日、high=最高、low=最低、close=末日、volume/amount=累计；weekly=W-FRI、monthly=ME），不落盘。
- ✅ 文档间决策已统一（2026-08-08）：三份缓存残留已清理，设计讨论.md 已降级为历史记录（决策以架构设计.md 为准）。

### 8.3 获取方案（序列 + 单点月频混合）

```
输入：code + start + end（目标日期范围）
① 序列（THS_DS）：窗口从【今天】往前 5 年（服务端视角，不是从 end 倒推）
   请求 [今天-5年, min(end,今天)]，返回多少算多少，得序列实际起点 ds_start
② 单点（THS_BD 月频）：范围 [start, ds_start)，采样点=每月【日历月末日】（1/31、2/28…）
   获取顺序从 ds_start 往 start 倒序（先近后远）→ 中断只丢最老数据，不会中间断
③ 合并：近 5 年逐日 + 早期月频点，排序去重；部分失败不丢弃（{ok, data, failed, notes, elapsed}）
```

**关键决策**：

1. 近 5 年窗口以今天为锚：THS_DS/HistoryQuotes 限制是"最近 5 年"（服务端视角），不是任意窗口。
2. **日历月末日方案（无需交易日历）**：THS_BD 非交易日自动返回最近交易日值 → 日历月末日请求 = 该月最后一个交易日的股本（月末当天是交易日→当天值；不是→前一个交易日仍在本月；长假横跨月末→节前最后交易日值，语义正确）。与"交易日历月末"结果一致，省掉日历调用。
3. 月频采样理由：股本低频变化 + 市值估算用前置填充（merge_asof backward），月频足够；单点串行慢且耗配额，2010~2021 月频 ≈ 139 次请求 ≈ 1-2 分钟（全量逐日 2900 次 ≈ 25 分钟）。
4. 获取顺序先近后远：序列完整拿近 5 年，单点倒序补早期，限额/失败只影响最老数据。
5. **多源冲突规避**：同一字段同一公司只走单一来源链（字段为中心）；月频点与日频点并存无冲突（同源同口径，前置填充取最近点）；跨源口径差异需防（yfinance Ordinary Shares 扣库存股 vs iFinD total_shares 可能含库存股，0700.HK 差 87M）→ 缓存带 source 元数据，不跨源填充。
6. 股本处理：总股本、流通股本都优先走ifind，最近5年内优先走序列请求，更早期才走单点请求，股本只请求月频数据，降低ifind限额。A股可以用AK新浪作为流通股回退方案，但当前阶段避免使用财报来提取对应股本（数据太杂，容易错，后期确有需要再处理）
