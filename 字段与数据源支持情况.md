### 1.4 复权口径（已定稿，2026-08-08）

- **除权价**：源直取，核心组一次打包。
- **后复权价**：源直取（iFinD CPS:3 / 东财 hfq / 新浪 hfq），不做任何处理。
- **前复权价**：**本地计算，不依赖源、不缓存**：`前复权(t) = 后复权(t) × (最新不复权收盘 / 最新后复权收盘)`，因子取同一交易日，随分红自动更新。
- 缓存只存 raw + hfq 两个文件（静态历史永不过期）。
- **成交量/成交额不做复权处理**（2026-08-08 实测：新浪港股 raw/qfq/hfq 三档下 volume/amount 完全相同）——复权只作用于价格。
- 周/月线：由日线本地聚合（open=首日、high=最高、low=最低、close=末日、volume/amount=累计；weekly=W-FRI、monthly=ME），不落盘。
- ⚠️ 文档间旧决策残留：`docs/market-data设计讨论.md` §3.1 仍写"直接请求 qfq/hfq/raw 三份缓存三个文件"，与 2026-08-08 定稿（两份缓存+前复权自算）矛盾——**以架构设计.md 2.2 为准**，设计讨论.md 待同步。

## 8. 股本（总股本/流通股本）数据源与获取方案（2026-08-08 讨论定稿，未编码）

### 8.1 背景

- 股本用途：总市值/流通市值估算（股本 × 不复权收盘价，逐日对齐）。**股本低频变化**（回购/增发/解禁/送转才变）→ 月频采样足够估算市值。

### 8.3 获取方案（序列 + 单点月频混合）

```
输入：code + start + end（目标日期范围）
① 序列（THS_DS）：窗口从【今天】往前 5 年（服务端视角，不是从 end 倒推）
   请求 [今天-5年, min(end,今天)]，返回多少算多少，得序列实际起点 ds_start
② 单点（THS_BD 月频）：范围 [start, ds_start)，采样点=每月【日历月末日】（1/31、2/28…）
   获取顺序从 ds_start 往 start 倒序（先近后远）→ 中断只丢最老数据，不会中间断
③ 合并：近 5 年逐日 + 早期月频点，排序去重；部分失败不丢弃（{ok, data, failed, notes, elapsed}）
```

**关键决策**：

1. 近 5 年窗口以今天为锚：THS_DS/HistoryQuotes 限制是"最近 5 年"（服务端视角），不是任意窗口。
2. **日历月末日方案（无需交易日历）**：THS_BD 非交易日自动返回最近交易日值 → 日历月末日请求 = 该月最后一个交易日的股本（月末当天是交易日→当天值；不是→前一个交易日仍在本月；长假横跨月末→节前最后交易日值，语义正确）。与"交易日历月末"结果一致，省掉日历调用。
3. 月频采样理由：股本低频变化 + 市值估算用前置填充（merge_asof backward），月频足够；单点串行慢且耗配额，2010~2021 月频 ≈ 139 次请求 ≈ 1-2 分钟（全量逐日 2900 次 ≈ 25 分钟）。
4. 获取顺序先近后远：序列完整拿近 5 年，单点倒序补早期，限额/失败只影响最老数据。
5. **多源冲突规避**：同一字段同一公司只走单一来源链（字段为中心）；月频点与日频点并存无冲突（同源同口径，前置填充取最近点）；跨源口径差异需防（yfinance Ordinary Shares 扣库存股 vs iFinD total_shares 可能含库存股，0700.HK 差 87M）→ 缓存带 source 元数据，不跨源填充。
6. 股本处理：总股本、流通股本都优先走ifind，最近5年内优先走序列请求，更早期才走单点请求，股本只请求月频数据，降低ifind限额。A股可以用AK新浪作为流通股回退方案，但当前阶段避免使用财报来提取对应股本（数据太杂，容易错，后期确有需要再处理）
