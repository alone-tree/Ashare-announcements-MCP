# market-data 改造设计（2026-10-19 定稿版）

> **文档性质**：本轮 market-data MCP 改造的**唯一设计文档**（合并 2026-10-14 需求、10-16 蓝图、10-16 改造思路、改造目标规格、财报工具重构设计五份文档，已去重、已剔除被否方案）。
> **地位与归宿**：改造时只看本文 + 《market-data架构设计.md》（现状决策）+《字段与数据源支持情况.md》（上游实测）；每步实施完成后，把定稿决策更新进架构设计文档。
> **前置条件**：标注「待手册」的条目在拿到官方手册前不得开工（铁律 1：iFinD 参数严禁猜测/试探变体）。

## 1. 范围与总原则（拍板记录）

| # | 决策点 | 结论 |
|---|---|---|
| 0a | 本轮范围 | 只做 market-data MCP/CLI（含 chart），公告 MCP 不动 |
| 0b | 分层分工 | MCP/CLI=基础设施（通用供数）；脚本=提取层（专用整理导出）；Excel 模板=需求清单（第一批字段依据） |
| 0c | 市场优先级 | 第一批只做 **A 股一般企业**全域；港美既有实现保留不动、延后；金融行业（银行/保险/券商）延后 |
| q1 | 改造激进度 | **只动数据源，框架完全不动**：工具面、缓存结构、模块分层全保留。改造=逐字段切 iFinD + 补新数据域 |
| q2 | chart 归宿 | **并入 market-data 单 MCP**（§3.6） |
| q3 | profile 五 section | A 股全切 iFinD 单源，补充源补全机制全部删除 |
| q4 | get_financial_ratios | 用 iFinD 实现（估值快照+财务比率）；原「东财英文列名」设计作废 |
| q5 | 财务摘要 | MCP 不加功能：脚本层调 get_financial_statements(items=[精选科目]) 现取 |
| q6 | A 股流通股本 | 切 iFinD：复制架构 §7.2 总股本方案（THS_DS 近 5 年 + THS_BD 日历月频补早期）；接受月频采样变化点当日精度损失 |
| q7 | 来源标注 | 保持现状两级结构：items=[{date,value,source}] + {ok,source,fields,error,notes}；iFinD 指标代码不进返回结构，审计看 logs/requests.jsonl |
| q8 | 已知 bug | 只修随切源自然消失的（holders 串公司）；美股回填测试红、end=周末挂起本轮不修 |
| f1 | 财报科目集 | **穷举 iFinD 一般企业模板全量**（现 318 项=用户 Excel 模板公式全集，非全量）；用户导出全量清单→AI 转注册表；金融专用行照现状标不适用 |
| f2 | 财报拉取粒度 | **按报告期惰性拉取**（2026-10-19 用户推翻 10-16 全量首刷拍板）：建档=立科目×报告期空表框架，不拉数据；查询时缺哪期拉哪期（每期 1 次 BD 请求约 1 秒）；**全量补齐不走 MCP**——需要全部数据时由脚本经 CLI 按日期范围逐期调取（符合 0b 分层：MCP 通用供数，脚本专职批量） |
| f3 | 财报报表类型 | **只做合并报表**（口径 100）；母公司报表延后（不实现、参数不留） |
| f4 | 市场探测 | **不做**：维持强制市场后缀路由，输错代码上游报错 |
| f5 | 科目推荐 | **不内置**模糊推荐：AI 先调 get_data_catalog 拿全量可用科目再取数 |

**数据源总逻辑**：每数据域一个唯一源；iFinD 默认首选；仅两类例外——①物理硬边界（行情 raw 全历史，见 §2）保留现源入白名单；②已拍板延后的港美域不动。同一域内 iFinD 序列+单点两通道组合允许（同一供应商，但须口径一致，见 §2 复权语义）。上游临时失败不换源、不静默兜底。

## 2. iFinD 渠道约束（实测，详见《字段与数据源支持情况.md》§7）

| 渠道 | 形态 | 历史窗口 | 速率 | 月配额 |
|---|---|---|---|---|
| THS_BD | 单点（一次一指标一时点） | 不限 | 串行 0.5-1 秒/请求，不支持日期区间 | 60 万点 |
| THS_DS | 序列 | **限最近 5 年** | 快（约 0.1 秒/请求） | 60 万点 |
| THS_HQ | 序列（行情） | **限最近 5 年** | 快 | 100 万点 |

- 三渠道配额独立；额度用完不静默换通道。
- **行情 raw 全历史（6000+ 交易日）用 iFinD 逐日补全=每股 50-100 分钟+2-4 万点，物理不可行 → 行情 raw 留新浪**（白名单）。
- 「近 5 年 iFinD + 更早新浪」混源拼接**禁止**（违反每字段唯一源）。
- 复权语义分市场（已验证，不得混用）：A 股 DS `107`=现金分红、HQ `CPS:3`=现金分红；美股 DS/BD `107,OC`=分红再投（与现金分红同日差异实测约 26.4%）、HQ `CPS:7`=现金分红；港股 iFinD 与新浪 hfq 比值随时间变化，切源须重建历史、不可常数缩放拼接。
- 价格覆盖已测成立：A/B 股 raw OHLC=`CPS:1`、hfq=`CPS:3`、qfq=`CPS:2`；港股 raw/hfq OHLC+量额、美股 raw OHLC+量额均已测。

## 3. 改造后工具面（6 工具）

### 3.1 get_quote —— 唯一改动：流通股本切源

参数、返回、字段级 9 json 缓存、覆盖判定（实际日期范围+10 分钟重试窗）全部不变。字段源变化：

| 字段 | 改造后 |
|---|---|
| raw OHLCV（全市场） | 新浪不变（物理硬边界白名单） |
| close_hfq | 不变（A/港新浪；美股 iFinD THS_DS+BD 既有方案） |
| total_shares | 不变（iFinD §7.2） |
| floating_shares | **全市场 iFinD**：A/北交所复制 §7.2（THS_DS 近 5 年+THS_BD 日历月频补早期，非交易日回落最近交易日），指标写法待手册 |

派生（qfq/市值=股本×不复权收盘/换手率/周月线/hfq OHL 还原）全现算不变。注意：outstanding_share（对外）↔ floating_shares（内部）对应关系不变；月末采样股本前向填充属估算序列，返回须可区分。

### 3.2 get_financial_statements —— 契约不变，注册表扩全（重点）

A/北交所唯一源=iFinD THS_BD（已切）；港美=东财延后不动。唯一实质改动：`src/market_data_mcp/financial_subjects.py` SUBJECTS 从 318 项扩到 iFinD 一般企业全量（f1）。

- 工作流：带后缀代码→查缓存→无则建档（空表框架，不拉数据）→请求日期范围内缺失的报告期逐期拉取并落缓存（single 差分所需前期自动纳入）→items 返回层过滤→markdown 矩阵+JSON 信封；
- 未命中科目报错（failed_items），不做模糊推荐（f5）；不做市场探测（f4）；不做母公司报表（f3）；
- 既有行为不变：amount_basis 必填、single 相邻累计差分（EPS 等非加总项不相减并提示）、annual+single=Q4 等季度组合、30 天新鲜期+force_refresh、版本链保留（本轮不新增投入）、同报告期多版本、三表批次全有或全无、审计意见行恒空（-209）；
- get_data_catalog 随扩表自动受益，保持纯本地不联网；惰性拉取下其「有值科目+最早最晚报告日」只反映**已拉取**的报告期，未拉取期间不可见（按需语义的自然结果；需要时直接查询对应期间即触发拉取）。

### 3.4 get_financial_ratios —— 从未实现 → iFinD 新实现

估值快照（PE/PB）+ 财务比率（营收/归母/扣非/毛利率/ROE/经营现金流第一批）；金额项优先复用三表，比率取 iFinD 明确口径值；指标中文名原样返回（不附指标码，q7）。缓存按日新鲜（区别于 profile 30 天），口径待指标集定稿。历史市值/估值序列是否开放待需求。指标集与写法**待手册**。

### 3.5 get_company_profile —— 五 section 全切 iFinD（A 股）

| section | 改造后 |
|---|---|
| profile 概况 | iFinD 单源（原巨潮） |
| ipo | iFinD 单源（原巨潮+新浪补全，补全机制删除） |
| dividends | iFinD 单源（原东财+3 源补全，删除）；预案/批准/实施不重复相加，不分配记录不伪装缺失 |
| forecast | iFinD 单源（原东财+同花顺补全，删除）；预测年份不写死，不混合不同机构样本 |
| holders | iFinD（串公司 bug 随切源消失）；保留历史多期十大股东；十大股东≠十大流通股东 |

30 天新鲜期缓存结构不变；旧 A 股 holders 缓存不可信，切源后重建。各 section 接口与指标**待手册**（分红注意 A 股 107=现金分红的分市场语义）。

### 3.6 get_quote_chart —— 并入 market-data 单 MCP

| 项 | 改造后 |
|---|---|
| MCP | get_quote_chart 注册进 market_data_mcp/server.py，共 6 工具；market-data-chart MCP 注销（hermes mcp remove+用户版重导出） |
| 代码 | 绘图并入 market_data_mcp 包，同包调用 service |
| CLI | market-data CLI 加 chart 入口（chart_batch），契约与 MCP 一致 |

功能不变：K线（蜡烛+成交量副图+MA5/10/20/60，按当前周期算，数据不足不画）/折线（field 任选 OHLC 无均线）；events 事件标注（对齐不早于事件日的最近交易日）；keypoints 仅折线（回撤阈值默认 0.30）；log_scale 含 0/负自动退回；红涨绿跌；PNG 落 cache/_charts/ 只返回路径；不传日期=全部缓存数据。不做多资产同图/财务图/模板系统。

### 3.7 主营构成（新域，归属 statements 扩展）

行业/产品/地区三维度平行分类（不可加总）：报告期、项目、收入/成本/利润及占比。结果单独区块，不混入三表科目行。iFinD 获取方式**待手册**。

## 9. 验收样例（改造后合格标准）

| 场景 | 合格结果 |
|---|---|
| 单公司近期行情（600519.SH 最近 10 日 close/volume） | 日期、单位、来源明确，短结果直接返回 |
| 全历史后复权收盘 | raw=新浪全历史；美股 hfq 按 BD 补全或明确范围；不存在静默截断 |
| 精选科目财报（600106.SH 营收/归母/扣非/现金流近 5 年） | 报告截止日矩阵，科目码可追溯 |
| 单季利润（某年 Q2，single） | Q1 参与相减，EPS 不相减并提示 |
| 三表历史修订 | 原版本保留可查，不伪造未观察的版本 |
| 股东历史 | 公司一致，截至日与公告日分开，数量比例单位明确 |
| 主营构成 | 分维度返回，不把两维度收入合计 |
| 盈利预测 | 年份动态、统计口径明确，不混机构样本 |
| 行情图 | PNG 可读，数据与 get_quote 一致，事件对齐正确 |
| 少量公司比较（CLI 三家） | 各自币种报告期可见，一家失败不抹掉其余 |
| 额度不足/代码非法 | 清晰报错，不静默换源 |
