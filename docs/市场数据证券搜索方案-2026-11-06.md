# 市场数据证券搜索方案

状态：方案已确认，待实施。用户确认AI自行判断是否补查，不在工具中固化补查流程。本次仅实现基础证券搜索与标准代码转换，不导出、不部署。

## 1. 问题及已确认决策

市场工具入口要求带市场后缀的代码，现行解析见`src/market_data_mcp/routing.py`；工具总览见[架构](market-data架构设计.md)。仅知道公司名称的AI缺少市场MCP内部的证券搜索入口。

2026-11-06用户确认：允许市场MCP使用东方财富公开证券搜索接口，公告与市场两个MCP各自独立调用。付费资料继续按各字段既定来源获取，本次不调整iFinD账号配置或取数通道。

## 2. 已确认方案

新增一个MCP工具`search_securities(keyword: str)`，CLI对应`search_securities`，接收同一个关键词并共用业务实现。工具定位为证券搜索，不附带建档动作。

流程：关键词 → 市场包自行请求东方财富 → 返回候选及标准代码 → AI选择证券 → 调用已有市场数据工具。

- 关键词支持公司名称、简称、简称片段或代码。每次调用只搜索该关键词；补查及合并展示由AI自行判断，工具不固化补查流程，不承诺找全关联证券。不按同名归组合并，不自动选中证券。
- 忠实保留上游候选和总命中数，不套用公告建档过滤。超过返回上限时提示缩小关键词。
- 候选保留上游原始证券字段，增加`standard_code`供市场工具直接使用。该字段按明确的市场/交易所证据转换，不按数字前缀猜市场；转换失败或该类型没有可用通道时留空，原始候选仍返回。
- 证券搜索返回标准代码只代表代码转换，不承诺每一项数据源均有该证券的数据。字段能力继续遵守既有契约。
- 不保存公司注册表或公司关联，不查询公告，不同步公告或互动问答，不读取公告缓存，不登录iFinD。
- 实现位于`market_data_mcp`包，不导入公告包、不调用公告MCP、不建立两个MCP的共享运行模块。

候选字段以公告现有`check`原始字段集合为参考，避免先自行裁剪市场识别所需信息；接口响应形态保持`keyword/source_total_count/returned_count/candidates`，新增字段只放在候选内。来源客观事实仍引用下节，不在此复制接口参数表。

## 3. 已核对证据与验证边界

上游接口及字段的既有证据见[公告主文档§8.1](AH公告与互动问答改造方案.md#81-东方财富证券搜索)；本轮不修改公告工具或其文档。

本轮通过公告MCP仅调用`establish_company(action="check", keyword="中芯国际")`进行只读实测：返回8个候选，688981为科创板、00981为港股，其余6条为期货。该样本支持分别呈现A/H证券并保留类型信息。此调用不是新市场搜索工具的验证。

预期新工具中上述两条股票候选分别增加`688981.SH`、`00981.HK`；这些是提案预期，尚未实现。沪深A/B、北交所、港股、美股的转换字段须逐个真实调用核对后才能实现，不能把一个样本外推为全市场验证通过。

## 4. 确认后的实施计划

1. 逐个实测各市场代表样本及歧义结果，确认原始字段到标准代码的转换规则；特殊代码先核对现有解析器边界，遇到不兼容先报告，不扩大本次范围。
2. 在市场包内增加独立搜索请求与转换实现，注册MCP及CLI入口；使用相同业务函数，不修改公告侧。
3. 验证标准代码可被市场解析器接受、不同市场同名候选保留、非股票及未知类型不会导致整批失败、上游失败如实返回、结果超过上限时有提示。覆盖MCP和CLI的真实调用，确认不依赖公告包、公告缓存或iFinD登录。
4. 行为契约更新到市场架构，市场搜索实测记录归支持情况，变动历史归决策记录；工具总览同步AGENTS。不得在多个长期文档重复定义转换规则。
5. 按项目要求本地提交验证通过的改动；不推送、不导出、不部署。完成后将本文按项目文档规范保存到Git历史并收尾。

## 5. 用户补充需求及补查分歧（2026-11-06）

用户补充期望：输入“旭创”应能呈现中际旭创A股、港股及标准代码；输入京东方A的代码也应能找到京东方A、京东方B。这里理解为寻找同一发行人的其他上市证券，不扩展为查询子公司或集团股权关系。

逐个真实调用公告MCP的check核对上游，观察如下；这些不是新市场工具的验收结果。

| 关键词 | 实际返回 | 缺口及后续观察 |
|---|---|---|
| 旭创 | 总命中59，返回20；其中300308为中际旭创，另外19条为港股权证 | 首批没有03308；按完整简称“中际旭创”补查可返回300308及03308两条 |
| 000725 | 返回京东方A、同代码韩股、一只货币基金，共3条 | 没有200725；代码本身也存在跨市场歧义 |
| 京东方 | 返回京东方A 000725、京东方B 200725、京东方精电00710，共3条 | 可找到A/B，但名称匹配也会命中另一上市主体，不能仅凭名称声称三条均为同一发行人 |

这些结果说明单次搜索不能保证找全同一公司的证券；同名候选与同一发行人关系不能混为一谈。

用户已选择由AI自行判断补查并合并展示，并进一步明确相信AI的基本常识，有需要会再要求AI尝试其他查询。因此工具及说明不加入固定的多次查询流程；标准代码仅对现有市场解析器可接受的股票候选提供，其余保留原始信息。
