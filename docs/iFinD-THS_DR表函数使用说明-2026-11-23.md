# THS_DR表函数使用说明（2026-11-23实测）

记录iFinD Excel插件中 `THS_DR` 这一函数的调用方式和实测结论。它与项目原有的 `thsiFinD` 是两套不同机制，不互相替代：`thsiFinD` 取单值，`THS_DR` 取整张表。

## 一、它和thsiFinD的区别

| 项目 | thsiFinD | THS_DR |
|---|---|---|
| 输入 | 指标码 + 代码 + 日期 + 参数 | 报表编码 + 字段名列表 + 参数区 + 输出区 |
| 输出 | 单值，一公式一值 | 二维表，函数写到指定区域 |
| 表头 | 调用方自己定义 | 上游生成，形如 `p03473_f001` |
| 前置条件 | 无 | 输出区表头必须先手工填好 |
| 现有支持 | 公式库753条已验证 | 本项目此前无记录，本文件为首份 |

用途上取长补短：`THS_DR` 用于取 `thsiFinD` 没有的指标（成分股名单、分地区收入、客户供应商集中度这类表格型数据），不改变现有 `thsiFinD` 的取数路径。

## 二、公式结构

实测通过的原式（工作表 `data` 页）：

```
=@THS_DR("p03473","iv_date,iv_zsdm",D6:D7,C8:E8)
```

四个参数：

| 位置 | 实测内容 | 含义 |
|---|---|---|
| 1 | `"p03473"` | 报表编码。本项目目前只确认 `p03473` 一个 |
| 2 | `"iv_date,iv_zsdm"` | 要返回的字段名，逗号分隔。应输出几列就写几个 |
| 3 | `D6:D7` | 参数值区域，按顺序对应该报表需要的入参 |
| 4 | `C8:E8` | 数据写入区域，列数须与第2参数一致 |

`p03473` 的实测行为：第3参数两格依次是日期（`20261123`）和指数代码（`000300.SH`），返回沪深300成分股名单三列（日期、同花顺代码、证券名称）。第2参写 `iv_date`、`iv_zsdm` 对应前两列，第三列证券名称即使不写进第2参也会返回。

## 三、必须前填输出区表头（踩坑结论）

这是最容易踩的一步。函数要求输出区域的首行先写好表头，表头名字形如 `p03473_f001`、`p03473_f002`、`p03473_f003`（报表编码 + `_f` + 序号）。不填则函数只回显参数、不写入数据。

实测隔离结果（同一实例、同一公式，只改动是否预填）：

| 预填C8:E8 | 输出区 | 结果 |
|---|---|---|
| 否 | C8:E400 | 失败，只回显参数 |
| 否 | C8:E8 | 失败，只回显参数 |
| 是 | C8:E8 | 成功 |
| 是 | C8:E400 | 成功，一次返回301行 |

所以起作用的是预填表头，不是区域大小。曾误判为"输出区必须恰好等于列数"，已由第4行否证。

## 四、完整操作顺序

按此顺序写，缺一步都取不到数：

1. 清空 `data` 页。
2. 填参数区：`D6` = `20261123`，`D7` = `000300.SH`。
3. 填输出区表头：`C8` = `p03473_f001`，`D8` = `p03473_f002`，`E8` = `p03473_f003`。
4. 在公式格写 `=@THS_DR("p03473","iv_date,iv_zsdm",D6:D7,C8:E400)`，公式格选在参数区之外的空白位置（实测用 `C5`）。

## 五、返回数据的落点

以 `C5` 放公式、`C8:E400` 为输出区为例，实测布局如下：

| 位置 | 内容 |
|---|---|
| C5 | 报表名称（文本，参数回显） |
| D5 | 指数成份（报表编码对应的中文名） |
| D6 / D7 | 参数值回显 |
| C8:E8 | 表头 `p03473_f001` / `f002` / `f003` |
| 第9行 | 中文列名：日期 / 同花顺代码 / 证券名称 |
| 第10行起 | 数据 |

沪深300实测共301行数据，`UsedRange` 到第309行。

## 六、等待数据完成的方式

不能沿用 `fetch_matrix` 的判断逻辑。`fetch_matrix` 靠"单元格是否还在显示抓取/提取"和Excel计算状态判断，而 `THS_DR` 是往区域里逐步追加行，判断依据应是行数不再增长。

实测时序：写入公式后约1秒数据即到位（301行），之后不再变化。判稳策略取"连续多轮有数据行数不变"。

注意：本项目此前的探针脚本曾因只判断固定时长、不判断数据是否到位，导致Excel早已出数却仍空等45秒。接进CLI时必须用行数判稳，不要用固定等待。

## 七、未确认事项

以下均未实测，不写入结论，需要时向用户索取插件界面原文：

- `p03473` 之外还有哪些报表编码，各自对应什么数据。
- 每个报表编码有哪些可用字段名（`iv_date`、`iv_zsdm` 之外）。
- 第2参缺省某些字段时是否影响列数对齐。
- 输出区列数与第2参列数不一致时的报错行为。

按项目铁律，iFinD参数严禁猜测变体，以上只能由插件界面原文确认。
