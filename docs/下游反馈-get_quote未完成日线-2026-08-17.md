# 下游反馈：get_quote 输出未完成日线

- 日期：2026-08-17
- 状态：待处理（未拍板改法）
- 来源：下游 `personal-investment-news` / `company-daily-brief` 早 7:00 简报
- 归属：现象与复测。改不改、怎么改，等本仓库拍板后再写入 `docs/market-data架构设计.md`

## 现象

下游每天用 CLI `get_quote_batch` 拉关注公司最近 5 个自然日行情，取**最后一行**当最新收盘。2026-08-17 周一 07:02 简报变成：

- 美股：有收盘价，涨跌幅全是 `+0.00%`，市值/成交量为空，日期写成当天
- A/H：全部「无行情（未上市或数据缺失）」
- 周五（8/14）的完整日线其实在上一行，下游没看到

与本仓库已拍板边界冲突：架构文档写明 **不做实时行情，只做历史日/周/月线**。

## 复测（2026-08-17 上午，用户版 CLI）

同一请求：`vars=close/volume/amount/turnover/outstanding_share/total_market_cap/float_market_cap`，`adjust=qfq`，`start_date=2026-08-12`，`end_date=2026-08-17`。

`NVDA.US`：8/12–8/14 字段齐全；多一根 **8/17**：`close=225.16`（与周五相同），`amount` 也是周五值，`volume` 为 null，无市值。

`300308.SZ`：8/12–8/14 字段齐全；多一根 **8/17**：`close/volume/amount` 全是 null，仍有 `outstanding_share`。

`ok=true`，`status=success`。不是整单失败。

## 代码位置

`src/market_data_mcp/service.py` `get_quote` 组装段（约 226–233 行）：

骨架日期 = 各字段缓存日期的**并集**，再按 `start/end` 裁剪。股本等字段会带上「今天」，close/volume 没有对应交易日，仍输出一行。美股 close/amount 还会把上一交易日的值写到这一天。

下游脚本只看最后一行：A/H 的 close 为 null → 判无行情；美股 last 与 prev 收盘相同 → `+0.00%`，市值算不出来。

## 影响

任何把 `end_date` 设为今天、并取最后一根 K 线当「最新收盘」的调用方，在**当日未收盘或当日非交易日**都会踩中。早盘/周末/节假日更明显。

## 未决（换电脑后从这里继续）

未拍板，不要先改代码。可选方向只作备忘：

1. 骨架日期只用价格字段（至少 close 非空）的日期，不要用股本并集
2. 输出前丢掉 close 为 null、或未收盘日的行
3. 未完成日单独标注（例如 `incomplete=true`），不混进普通日线
4. 维持现状，由下游自己跳过最后一根不完整 bar

与「不做实时行情」最齐的是 1 或 2。
