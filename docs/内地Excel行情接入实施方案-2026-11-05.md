# 内地 Excel 行情接入实施方案

日期：2026-11-05。状态：本轮实现及代表性真实流程验证已完成；实施前版本保存在486b288。现行行为唯一见[内地行情细则](行为-内地Excel行情.md)，本文仅保留实施清单，不另作行为规范。

## 范围

- 只实现数据 MCP 的 SH/SZ/BJ 股票行情闭环。公告 MCP、公告档案、建档入口全部独立，不调用或读取；此前跨工具建档流程不作为本轮实施依据。
- 公司信息只取行情必要的交易所、股份类型、上市日期，使用已验证的 iFinD SDK 原式及数据 MCP 自身缓存。不实施工商24项、IPO20项等完整重分组，不要求先建档，不新增公司查询工具。
- Excel 为内地行情唯一通道，无自动回退。港美股及汇率保持既有行为；旧通道代码保留。
- 现有 get_quote 参数签名、默认日期、复权方式和单证券输出保持；新增清晰的公司/证券总股本、总市值字段名，旧 total_shares/total_market_cap 明确作为公司字段兼容名称。内地流通股本、流通市值退出本轮接口支持，换手率改上游直取。

## 实现清单

1. `ifind_excel.py`：扩展为二维公式矩阵，整块写入、等待、读取和清空；原单列调用保留。单元格错误隔离到对应字段，不因为一个字段错误丢弃其他字段结果。专用实例、超时及隔离沿用现有实现。
2. 数据 MCP 内部最小证券资料：以标准代码缓存三个必要字段，复用30天刷新规则，保存上游原值；仅缺资料时请求 SDK。不依赖公告注册表或 A/H 关系。
3. 新增内地 Excel 行情适配：使用已验证的原式组装日期×字段矩阵，全部价格、均价、成交额、换手率、四个股本市值字段同批获取。成交量按成交额÷不复权均价计算；换手率将上游百分数规范为比值。
4. 接入既有字段缓存：新增必要字段，使用 `ifind_excel` 来源隔离旧行情口径。旧数据不删除；首次新来源写入该字段时不混入旧来源。只缺终点时从已缓存末日重叠补取，不按字段重复执行整包。失败保留同通道可用缓存及缺口，不接回旧通道。
5. `get_quote`：SH/SZ/BJ 调用新行情闭环，其他市场复用既有逻辑。前复权依已有后复权与区间末端有效原价本地缩放，后复权开高低直取；只对价格和均价复权，股本、市值、量额及换手率不随价格复权。
6. 日期：缓存保留日历日原值；输出使用已验证成交量大于零的有成交日，周末及全天无成交日不混入周月价格聚合，明确说明日期口径。上市前日期不补造成交。参数日期非法时在启动 Excel 前返回错误。
7. MCP/CLI 与帮助同步新字段及内地口径，提供专用 Excel 关闭入口；资源导出规则只更新源码，不实际执行用户版导出。
