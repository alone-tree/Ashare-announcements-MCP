### 2. iFinD 接口形态实测（2026-08-07，现仅用于股本）

- `THS_HistoryQuotes` 返回 **dict**（errorcode/tables[0]={thscode,time,table}），与 THS_BD/THS_DS（THSData 对象）返回类型不同。
- 币种：不传 Currency = 原始币种；`Currency:MHB` 反而折美元（坑）。
- 复权：`CPS:1`=不复权、`CPS:2`=前复权、`CPS:3`=后复权（数字格式）。
- 港股代码 `0700.HK` ✅，`700.HK`/`00700.HK` 报 -4210（要前导零）。
- 账号容灾：jdlhk001 登录 -1（不可用）、jdkgjt009 正常。
- iFinD 国内服务，清代理直连可用。
- **完整股本接口矩阵与公式速查见 `字段与数据源支持情况.md` §8.2。**

### 3. yfinance 股本三档（2026-08-07，港美股股本回退源）

- 年度资产负债表 Ordinary Shares Number（~5 年）、季度（近 2 年）、get_shares_full（2015 底起 ~10 年事件点）。
- 必须走代理 127.0.0.1:17891，直连被 Yahoo 限流；注意库存股（Ordinary = Share Issued − Treasury）。

### 4. B 股与 A 股同渠道验证（2026-08-07）

### 5. 外部代码强制后缀路由（2026-08-07，仍有效）

- `300476.SZ` / `600519.SH` / `900901.SH`(沪B) / `200725.SZ`(深B) / `00700.HK` / `AAPL.US`；不带后缀报错。
- 脚本按后缀路由市场，禁止按数字位数/开头猜测（"脚本不猜测，AI 负责灵活"）。
- 内部按源转换：iFinD 港股 4 位带前导零（0700.HK）、AKShare 5 位裸码（00700）。

### 6. 限流策略（简单，仍有效）

1. 先查缓存：够用 → 直接读，零网络。
2. 不够再拉：拉新数据入缓存。
3. 失败即重试：失败 = 缓存未更新 → 提示"缓存获取失败，请重试"，重试自动跳过已完成部分。
4. 字段链回退：见架构 1.4 字段表。

## 三、已删除的废弃表述（记录以便追溯）

1. **三份缓存**（qfq/hfq/raw 各一文件，"不引入复权因子本地计算层——因子源与口径不一致的坑比存储冗余更麻烦"）→ 废弃：前复权随分红变动，只缓存 raw+hfq，前复权本地计算（架构 2.2）。
2. **iFinD 行情第一来源** → 废弃：SDK bug + 付费仅 5 年，降级为仅股本（数据源文档 §0）。
3. **只返回元信息不返回数据本体** → 废弃：默认返回数据本体，超长自动导出，指定导出返回元信息（架构 1.6/2.5）。
4. **市值 iFinD 直接获取**（"市值不再需要 yfinance 股本链自算"）→ 废弃：市值=股本×不复权收盘计算法，股本链 iFinD→新浪/yfinance 仍然需要（架构 2.4）。
5. **从财报取季度股本反推历史股本** → 暂不做：复杂且易错，后需再处理（架构 2.4/6）。
