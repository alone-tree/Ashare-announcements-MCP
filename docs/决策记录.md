- 现在：每条规则只有一个家——协作规则/铁律/文档地图只在 `AGENTS.md`；工具行为只在架构设计对应章节；上游接口事实只在支持情况；科目清单只在 `ifind财务报表科目.md`。其他地方只能指路（如「见 `docs/行为-财报工具.md` §3」），不得复述。
- 为什么：重复维护必然不同步，不同步就有人（包括 AI）按过期的那份做事。
- 影响：AGENTS.md §八、铁律5（规则正文只在 AGENTS.md 维护，本文只记变动）。

## 2026-10-19 财报拉取改为按报告期惰性拉取

- 之前：首次调用即全历史回补约 120 个报告期，单期一次 `THS_BD` 带全量科目，合计约 4 万数据点；查一个数字也要付这个成本。
- 现在：建档只写空报告期框架、不拉数据；查询时缺哪期拉哪期（每期 1 次 `THS_BD`）；需要全部历史时走脚本经 CLI 按日期范围逐期调取，不在 MCP 内做全量首刷。
- 为什么：4 万点配额与约 2 分钟耗时对单个查询不成立；MCP 只做通用按需供数，批量补齐属于脚本层的活。
- 影响：架构设计 §1.5；细则见 `docs/行为-财报工具.md` §3（标❓待实现）。实现尚未跟上（代码仍为全历史回补），已登记方案稿§1。

## 2026-10-19 THS_BD 失败改为退避重试三次

- 之前：单期请求失败后睡 0.5 秒重试一次，仍失败即整批失败。
- 现在：1 次首发 + 3 次退避重试（0.5/2/5 秒）。
- 为什么：实测同花顺服务端偶发 `errorcode=-205 request data error`，数秒内自愈；0.5 秒单次重试扛不住，而回补是整批全有或全无，一期失败即白跑。
- 影响：`docs/行为-财报工具.md` §3；实测记录见支持情况 §7。

## 2026-10-19 iFinD 账号切换与账号顺序调整

## 2026-08-08 市值走计算法、字段为中心、默认返回数据本体

- 之前：市值直接取上游字段；行情三份复权缓存；统一"下载到缓存不返回数据本体"。
- 现在：市值=股本×不复权收盘现算，不从财报反推股本；每个字段独立来源链，不统一排数据源优先级；默认为直接返回数据本体，超过 200 行自动导出 CSV，指定 `export_path` 时导出并返回元信息。
