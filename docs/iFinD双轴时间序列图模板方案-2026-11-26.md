# iFinD 双轴时间序列图模板方案（2026-11-26）

状态：计划，待确认。第三块 features/ 新增标准绘图模板 `dual_axis_series`，沿用既有绘图规范（白底、无底色、字体放大、16×11、DPI200、tableau色板）。

## 一、效果

一次传多组时间序列，双轴合成一张图。典型用法：
- 一家公司：市值左轴+股价右轴
- N家公司：全部股价实线对数左轴，全部PE虚线普通右轴

时间对齐规则：每组数据自带时间点（ymd日期或相对天数1、2、3），按各自时间点落点绘制，不插值不造点，交易日不同的两家公司天然各画各的。一次调用内时间类型统一（全日期或全数字，按第一组判定）。

## 二、调用格式

```json
{"cmd":"draw","template":"dual_axis_series",
 "title":"贵州茅台：股价与市值",
 "output":"图.png",
 "left":{"log":true,"label":"总市值（亿元）"},
 "right":{"log":false,"label":"后复权股价（元）"},
 "series":[
  {"label":"总市值","axis":"left",
   "data":[["2026-11-13",18400.2],["2026-11-14",18520.5]]},
  {"label":"后复权股价","axis":"right",
   "file":"行情.csv","y_column":"收盘价"}
 ]}
```

| 参数 | 说明 |
|---|---|
| series[].label | 必填，进底部图例 |
| series[].axis | left/right，默认left |
| series[].dashed | true虚线，默认实线 |
| series[].color | 可选，默认按色板顺序自动分配 |
| series[].data | 内嵌 [时间,值] 数组；或用 file+可选 x_column/y_column 读CSV |
| left/right | 各自 log（默认false）与 label（默认空） |
| title | 顶部标题，可省 |

## 三、关键呈现

1. log轴刻度细化：按数据范围动态标刻度（1-2-5体系，范围跨度小于约1.5个量级时细化到2-9全标），显示实际数值文本，不是只有10-100-1000。
2. 图例自动合并左右轴全部系列，放图下方，一行排不下自动多行。
3. 左右轴标签文字染各自轴第一个系列的颜色，一眼对应哪条线在哪个轴。
4. 网格只画左轴刻度，避免双轴网格交错。

## 四、定位与扩展约定

标准基础模板，不做更多灵活性（不加标记线、注释、子图等参数）。个性化需求（水平/垂直标记线、事件标签等）：AI复制本模板到临时目录改，产出物不进正式模板清单，用完即弃或按需另议。

## 五、验收

1. 市值左轴+股价右轴（600519.SH真实数据）出图，双轴对应清晰。
2. 两家公司股价（实线log左轴）+PE（虚线右轴）四系列一图，图例完整。
3. 相对时间1、2、3模式出图正常。
4. 左log右普通混合可用，log刻度值可读。
