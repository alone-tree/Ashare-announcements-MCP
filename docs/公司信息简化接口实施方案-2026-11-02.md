# 公司信息简化接口实施方案

状态：已获用户授权实施；盈利预测默认未来三年，不含当前年度，已于2026-11-02确认。

## 范围与依据

以用户确认的XMind公司信息设计为依据，只改公司信息工具的调用及返回，不改行情、财报、绘图，不新增数据源、不调整缓存刷新间隔、不导出或部署。

现行接口一次选多个sections，years/periods/as_of_date含义随类型变化；forecast缺少years即失败，港美旧通道会忽略时间参数。本次改为一次查询一种类型，整类返回，额外参数按本次类型在结果中说明。IPO现有16字段、工商25字段及其他上游字段保持现状；XMind中的上市日期仍可从profile取得，不扩展本次接口改造范围。

## 已确认契约

MCP：`get_company_profile(code, information_type, force_refresh=False, extra_parameters=None)`。

information_type必填，为profile（工商/概况）、ipo（IPO）、dividends（年度分红）、holders（十大股东）、forecast（盈利预测）之一。extra_parameters为JSON对象；不提供科目筛选。CLI保留get_company_profile_batch及codes列表，其余参数与MCP相同，删除旧参数入口，不加兼容别名。

大陆市场额外参数：

| 类型 | 参数 | 默认 |
|---|---|---|
| profile、ipo | 无 | 完整信息 |
| dividends | dividend_years，非空整数数组，分红统计年度 | 本年及此前四年 |
| holders | shareholder_report_dates，非空YYYY-MM-DD数组，股东名单报告截止日 | 最新已披露一期 |
| forecast | forecast_years，非空整数数组，预测业绩所属年度 | 当前年度之后三年，2026年调用即2027—2029年 |
| forecast | forecast_as_of_date，YYYY-MM-DD，预测取数基准日 | 请求当天，取该日可用预测；不冒称上游实际更新日 |

报告截止日和取数基准日不得晚于今天。拒绝拼错、类型错误、不属于本信息类型及该市场不能执行的参数，不静默忽略。年度统计归属沿用上游，不将尚未核清的分红统计年度解释为利润所属年。

港股继续现有profile/dividends/forecast通道，保留其实际数据粒度，暂不接受大陆通道的年度/报告期/历史预测参数；返回中不宣传这些额外参数。IPO、股东及美股不可用边界不变。

## 返回与缓存

service/CLI单公司结果平铺code、market、information_type、data及来源、检查时间、缓存/失败等实际元信息，不再套单元素sections。有效时间范围在query回显；股东默认期末从实际检查记录取得。无可用通道保留available=false及原因；空值、零和未接入分别表达。部分范围失败或旧值沿用继续标注partial_success/stale。

MCP把data渲染为完整Markdown表，保留元信息；静态信息按字段/值成表，列表按实际列成表，嵌套值不丢弃。CLI保留原始结构化data。仅本类型本市场有可用额外参数时返回extra_parameter_help，包括参数名、用途、格式、默认行为及完整调用示例；基本工具说明保持简短。

沿用现有分证券、分类型、分时间范围缓存及30天策略。预测默认取数日先解析为明确日期，再参与已有缓存键，避免跨日将旧快照标为新日期。强制刷新只重查本次范围。禁止回退到旧新浪股东缓存。
