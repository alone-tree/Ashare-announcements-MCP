## 一、目标与边界

get_quote/get_quote_chart的HK后缀切到iFinD Excel整包通道；同时AB股矩阵同步瘦身（2026-11-06用户拍板，降低请求与缓存占用）：后复权直取只保留close_no_forward(107)与后复权均价(107)，开高低的后复权/前复权输出改按因子`F(t)=收后复权÷收`还原，前复权全部现算不落盘。两通道矩阵均为13列公式+派生量，完全同构。后缀路由不变，AI只传带后缀代码。

HK字段口径唯一以XMind「行情数据>HK股 .HK」分支备注为准（2026-11-06用户定稿）：OHLC和均价只取除权，均价另有后复权101直取，唯一后复权收盘=close_no_forward。

不动：美股（close_no_forward实测返回0，不接本通道）、汇率、公告侧、内地行为。新浪保留路径收窄为美股。港股旧新浪缓存按既有「切源只保留当前来源记录」规则自然淘汰，不批量删除。

### 行情矩阵编排规则（providers/excel.py层；运行层不假设此形状）

- 形状保持「行=日期、列=字段」：错误格按列定位字段、分块按时间连续段切并与缓存合并逻辑对应；不合成单列（无性能收益，COM调用次数与插件请求总数只与公式总数相关）。
- 行剔除周六周日：四市场股票正股周六周日均休市（事实规则）；节假日行保留（各市场节假日不同），输出层由close_no_forward=0兜底过滤。汇率走SDK通道不经Excel，不受影响。
- 单批2500行（约3.25万式，2026-11-09定案；门槛实测1万/2万/3万式×冷态3轮+热态全部稳定，历史故障与单批总量无关，分块定位为故障隔离单元）。
- 专用Excel保持前台可见常驻（visible=True，2026-11-09定案，便于用户管理；启动新实例与复用实例均不隐藏）。
- 块级故障校验（含全0判定）归属本层：全0在通用场景（财报科目、工商信息）可能合法，运行层不内置判定；行情层判定规则见下节。

### 行情0值判定（providers/excel.py层，2026-11-09分市场定案）

休市日回填行为分市场不同（实测）：A股OHL收全部回填前值非0；港股open/high/low=0不回填、close=前值非0、cnf=0、amount=0（0700/1398圣诞新年窗两码一致）。

**A股判定**：行级「高开低收全0且cnf=0」→请求失败，该块重试一次。A股休市/停牌行全回填非0，工作日矩阵内该形态必异常。

**港股判定**（停牌行为已实测）：
- cnf>0 → 交易日或个股停牌日，正常保留（停牌实证：00708恒大汽车2025-04-01起停牌，样本窗2026-08-03~11-07共97日历日——停牌工作日close/cnf=停牌前值恒定非0、OHL与均价回填非0、量额换手=0、周末cnf=0；68工作日cnf全覆盖）
- cnf=0 且 close（100参数）>0 → 市场休市日（节假日；OHL=0不回填为港股休市特征），正常保留，输出层过滤
- 块级兜底：整块close=0且cnf=0 → 请求失败，重试一次（仅上市前段会出现，start=all骨架裁剪后不应出现；长停股实证close全非0，兜底永不误触发）
- 部分行故障无观测样本，不预设行级判定

重试必须关闭Excel再重开：iFinD有缓存机制，仅重输公式会直接返回缓存结果，不产生真实重取。工商信息等通用场景正常不会出现0，出现0即请求失败，由各数据域上层各自判定；运行层不做任何数据语义判定。

与内地的实质差异（AB同步改造后两通道同构）：

1. 后复权直取均只有两列：close_no_forward与后复权均价（AB 107、HK均价101）。AB现行矩阵的open_hfq/high_hfq/low_hfq 3列直取同步移除；开高低的后复权、前复权输出用逐日因子`F(t)=收后复权÷收`还原（架构§2.3.b新浪链既有做法），前复权全部现算不落盘。矩阵均为13列公式+派生量。
2. 成交量派生：量=成交额÷均价，复权成交量用各口径自己的均价（后复权量=额÷后复权均价），脑图备注明确。
3. 缓存键：close后复权落close_no_forward，均价后复权落avg_price_hfq；开高低不落hfq键（AB旧open_hfq等缓存文件自然闲置，不批量删除）。
4. 输出单位：价格/成交额/两档市值=港元；换手率上游百分数÷100同内地。

## 六、边界实测结论（2026-11-06已完成，真实Excel取数约16万公式）

因子还原`F(t)=收后复权÷收`与直取的一致性，全部场景逐位一致（相对差≤1e-13，纯浮点精度）：

| 边界 | 样本与结果 |
|---|---|
| 现金分红跳变 | 600519×5次、900901×3次、200725×7次、0700.HK（2026-05-15），跳变日直取vs还原逐位一致 |
| 配股跳变 | 600030 2022-01-27（因子+6.07%），一致；配股停牌6个零成交日还原零超差 |
| 大比例送转 | 920002×2次（因子+40%）、603083 2020-08-13（+30%），跳变日逐位一致 |
| 拆股 | 0700.HK 2014-05-15（1拆5，因子+400%），一致（12年前历史数据101口径可用） |
| 市场类型 | 沪A/深A/创业板/北交所/沪B美元/深B港元/港股全部一致 |
| B股币种 | cnf与close同币种，因子纯净无汇率混合；900901早段1992拆细（+900%）一致 |
| 零成交段 | 900901早段2196个零成交日全部一致；avg_price早段缺失段如实跳过 |
| cnf覆盖完整性 | 300308/000001/300313/603083/900901/600519/600030/200725/920002九年cnf非0数=全部交易日数，无缺失（此前「300308缺失」系误选休市日） |

运行层与数据域层的边界及未定项（实测发现的边界）：

1. 分块取数：门槛实测（2026-11-09）1万/2万/3万式×冷态3轮+热态对照全部稳定（耗时：3万式冷态15-18秒、热态10秒左右），历史4次故障（均300308、集中11-06下午，含7503式小批量）未复现且与单批总量无关——定性为偶发批量故障，触发条件未定位。分块2500行/批保留，定位为故障隔离单元（单块故障只重试该块）。
2. 整批全0故障判定规则已分市场定案并全部实测闭环（2026-11-10）：A股按行「高开低收全0且cnf=0」；港股cnf>0交易日/停牌、cnf=0且close>0休市、整块close=0且cnf=0兜底重试。港股停牌实证（00708恒大汽车2025-04-01起停牌，样本窗2026-08-03~11-07）：停牌日cnf=停牌前值非0与A股一致，长停股块级兜底永不误触发。重试方式=关闭Excel再重开（iFinD缓存机制，仅重输公式不产生真实重取）。
3. COM忙重试：连续大矩阵后出现RPC_E_CALL_REJECTED，等待后重试即恢复——运行层1/3/5秒重试；关闭后立即重开同样被拒，重试序列需覆盖此场景。
4. 文本模式：运行层现把文本值当错误格收集；港股上市日期（"YYYY-MM-DD"文本）与营收结构名称（上游匿名化文本）都需要文本原样返回——合并实施。
