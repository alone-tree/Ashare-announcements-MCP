# 港股行情Excel接入方案（2026-11-06）

执行稿。完成后长期行为归[内地Excel行情细则](行为-内地Excel行情.md)（执行时随范围扩展改名），上游事实已落[支持情况§12/13/16](../字段与数据源支持情况.md)，本稿完成归档。

## 一、目标与边界

get_quote/get_quote_chart的HK后缀切到iFinD Excel整包通道，与SH/SZ/BJ同构：同一矩阵结构与缓存/复权/聚合加工框架。后缀路由不变，AI只传带后缀代码。

字段口径唯一以XMind「行情数据>HK股 .HK」分支备注为准（2026-11-06用户定稿）：OHLC和均价只取除权，均价另有后复权101直取，唯一后复权收盘=close_no_forward。

不动：美股（close_no_forward实测返回0，不接本通道）、汇率、公告侧、内地行为。新浪保留路径收窄为美股。港股旧新浪缓存按既有「切源只保留当前来源记录」规则自然淘汰，不批量删除。

## 二、上游依据（均已实测）

- 16列港股原式全部实测有效：价格与量额股本市值见[支持情况§12.1](../字段与数据源支持情况.md)（2026-11-04，3308.HK与简称10/10一致）、市值与币种见§13.5、close_no_forward及avg_price_hks/turnover_ratio_hks见§16（2026-11-06修正，0700.HK腾讯7式无错误单元格）。
- Excel港股代码=4位前导零（0700.HK），与[routing.py](../src/market_data_mcp/routing.py)的ifind_code一致；00700.HK/700.HK格式返回0。
- `close_no_forward,107` = `ths_close_price_hks,101` 逐位一致（腾讯2026-11-05）：与内地「close_no_forward=107参数收盘」结构对应，开市日判定（>0）、qfq锚定、close hfq缓存键全部同构复用。
- 复权口径：Excel枚举107/101均为普通「后复权」（P00374/P00072），不写分红定语（2026-11-06已纠正此前混用SDK口径的错误）。
- 市值币种枚举P00179（CNY/USD/HKD，默认HKD），公式显式传"HKD"，保持厂商原值不换算。

## 三、矩阵公式对照（执行依据，与脑图备注一致）

公式列13列+派生量1列；日期、代码逐格代入。代码格式：4位前导零0700.HK。

| 公开字段 | 内地spec（现行excel.py） | 港股spec（新增） |
|---|---|---|
| open | ths_open_price_stock,100,"" | ths_open_price_hks,100,"" |
| high | ths_high_price_stock,100,"" | ths_high_d_hks,100,"" |
| low | ths_low_stock,100,"" | ths_low_d_hks,100,"" |
| close | ths_close_price_stock,100,"" | ths_close_price_hks,100,"" |
| avg_price | ths_avg_price_stock,100 | ths_avg_price_hks,100,"" |
| avg_price_hfq | ths_avg_price_stock,107 | ths_avg_price_hks,101,"" |
| close_no_forward | close_no_forward,107 | close_no_forward,107（相同；周末节假日返回0，不填充前值） |
| amount | ths_amt_stock | ths_amt_d_hks |
| turnover | ths_turnover_ratio_stock | ths_turnover_ratio_hks |
| company_total_shares | ths_total_shares_stock | ths_corp_total_shares_hks |
| security_total_shares | 按份类ths_total_{a,b}share_stock | 固定ths_sec_total_shares_hks（当前证券H股股本，不按类型路由） |
| company_total_market_cap | ths_market_value_stock | ths_market_value_hks,"HKD" |
| security_total_market_cap | ths_mv_sec_oriented_stock | ths_totalcapitalforsecurities_hk,"HKD" |

与内地的实质差异：

1. 内地有5列后复权直取（`*,107`），港股只有均价后复权101与close_no_forward两列；open/high/low的后复权、前复权输出用逐日因子`F(t)=收后复权÷收`还原（架构§2.3.b既有做法），不落缓存。
2. 成交量派生：量=成交额÷均价，复权成交量用各口径自己的均价（后复权量=额÷后复权均价），脑图备注明确。
3. 缓存键：close后复权仍落close_no_forward，均价后复权落avg_price_hfq；open/high/low不落`*_hfq`键。
4. 输出单位：价格/成交额/两档市值=港元；换手率上游百分数÷100同内地。
