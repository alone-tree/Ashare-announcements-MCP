# Excel 行情行为

本文件维护get_quote在SH/SZ/BJ/HK的取数、字段和加工行为。港美汇率见[总架构](market-data架构设计.md)，原式、单位实测及样本边界见[支持情况](../字段与数据源支持情况.md)。

## 1. 范围和入口

数据MCP独立工作，不调用公告MCP、不读取公告公司档案、不要求公告建档。SH/SZ/BJ/HK股票统一使用iFinD Excel；失败如实报告，不切换新浪或SDK行情。美股价、汇率及旧来源代码保持既有路径。

get_quote参数签名、raw/hfq/qfq、daily/weekly/monthly、最近14自然日默认区间及CSV输出保持。代码须有市场后缀。start_date="all"从证券上市日期开始取数；已有本通道历史缓存可复用，不反复从1990年请求；骨架缓存起点晚于上市日时先从上市日补缺口。非法日期、倒序区间、未知或空字段列表在取数前拒绝。

| 公开字段 | 含义及单位 |
| --- | --- |
| open/high/low/close | 当前证券价格；A股人民币，沪B美元，深B港元，港股港元 |
| avg_price | 当前证券均价；内地原式返回人民币，B股亦为人民币；港股原式返回港元 |
| volume | 股；成交额÷不复权均价，分母无效时留空 |
| amount | 当前证券标准成交额；内地人民币，港股港元 |
| turnover | 上游换手率百分数÷100，0.025表示2.5% |
| company_total_shares | 公司全股本，股 |
| security_total_shares | 当前证券股份类别总股本，股；A/北交所选A股合计，B股选B股合计，港股为该证券总股本 |
| company_total_market_cap | 厂商公司总市值原值；内地人民币，港股港元 |
| security_total_market_cap | 厂商面向证券总市值原值；内地人民币，港股港元 |

四个公司/证券字段地位相同，补取区间同批缓存，输出由vars选择。旧total_shares、total_market_cap仅为公司字段的兼容名称，不表示默认选择公司层。内地不支持outstanding_share、float_market_cap，不取流通字段或跨市场分项加总；港股同（2026-11-09确认换手率足够）。

总市值原值固定为ths_market_value_stock与ths_mv_sec_oriented_stock（内地）、ths_market_value_hks与ths_totalcapitalforsecurities_hk（港股），保持厂商原值，不互换或补估非上市股份。同日两有效值出现公司值小于证券值时只提示倒挂。港股金额类原式显式传"HKD"，不做汇率换算。

## 2. 最小证券资料

company_ifind_service.get_quote_security按市场分通道。内地走已验证SDK原式取得交易所、股份类型、上市日期；港股走ifind_excel单公式ths_ipo_date_hks（文本模式），只取上市日期并规范化为8位数字，不取交易所或股份类型。记录位于数据根cache/{标准代码}/company_data/security.json，使用data_store的schema_version=2、30天刷新规则；港股source=ifind_excel，内地source=ifind。不实施完整工商/IPO重分组。公开证券搜索是独立入口，见[总架构§9](market-data架构设计.md#9-证券搜索工具-search_securities)。

上市日期必须整项读取：单列接口返回一维values，取首项完整字符串再规范化，不得按下标截取字符或按列宽截断（2026-11-13缺陷见[决策记录](决策记录.md)）。

行情缓存覆盖时不请求证券资料或启动Excel。需要取数且资料不存在或过期时才请求；资料失败不阻断无需分类的价格，未知股份类型不默认A股，证券总股本明确缺失。缺少分类时价格单位标明未确认，不按数字前缀推断。港股不依赖股份类型，四个公司/证券字段始终可取。

## 3. 矩阵、缓存和错误

一次整包13列上游字段：原始OHLC及均价5列、后复权收盘close_no_forward 1列、后复权均价1列（内地107参数、港股101参数）、成交额和换手率2列、公司/证券股本及市值4列。开高低的后复权不再直取，由因子还原现算（§4）。每行一个日历日，每列一个字段，完整区域一次写入、等待、整块读取，前后清空工作页，专用Excel保持常驻；不拆为逐列或逐行COM请求。未知股份类型时只略过依赖分类的证券总股本列。矩阵由providers/excel.py构建，执行器见[运行说明](Excel常驻运行层.md)。

缓存使用既有cache/{代码}/{字段}.json，source为ifind_excel，只保存该通道上游原值，不持久化前复权或成交量计算值。同来源历史与新增区间合并；某字段切入新来源时只保留当前来源记录，旧来源不满足新通道覆盖。本轮不批量删除正式缓存。

先检查请求字段和日期依赖，对缺口执行一次整包；仅终点不足时从已有效的尾部重叠补取，沿用10分钟末端不足复用规则。开市日以close_no_forward大于零识别（0=周末节假日休市）；start=all时骨架缓存起点必须不晚于上市日，否则先从上市日补缺口。周末零量或当日未更新值不视为永久覆盖；查询包含当天时按10分钟窗口重查，不判断收盘时刻。成功得到的其他字段一起落缓存，不为同次请求其他列再次取同一区间。

整批返回0视为疑似故障并重试一次（关闭Excel后重开，仅重输公式不产生真实重取）。判定分市场：内地按行判「开高低收全0且cnf=0」；港股按整块判「全部行收0且cnf=0」，停牌日cnf为停牌前值非0，长停股不会误触发。

单元格错误报告日期和字段，该列本批不提交，其他成功列独立持久化。真实空值和零值保留，错误不写成成功空值。失败可返回同通道已有数据及缺口，不推进失败字段更新时间；无请求字段可用则失败，部分可用为partial_success。不跨通道补空。

缓存保存日历日原值；输出列出全部市场开市日（close_no_forward大于零），公司停牌及全天零成交日保留行、量额换手为0，notes明确日期口径。成交额不可用时报告日期依赖缺失。上市前零值保留原始缓存，不产生虚构成交日。

## 4. 复权、聚合及输出

后复权收盘读取close_no_forward列，后复权均价读取avg_price_hfq列，开高低的后复权由因子还原：F(t)=后复权收盘÷原始收盘，后复权开高低=原始值×F(t)，两市场同式。前复权在请求范围末端有成交日中选择同日有效原始/后复权收盘价作锚：前复权价格=后复权价格×锚定原始收盘价÷锚定后复权收盘价；均价使用自身同日原始/后复权均价比例，避免B股币种混用。缺基点不给伪造价格，基础缓存不因输出复权类型改变。

股本、市值、量额及换手率不随价格复权。周/月由上述开市日行加工：OHLC常规聚合（开=周期首日、高取max、低取min、收=末日），量额和每日换手率累计，股本市值取期末，均价按日均价与不复权成交量加权。不调用其他源填充日期。

结果含code/market/start/end/adjust/period/vars/source、ok/status、notes及逐字段units，source=ifind_excel。units按市场标注：内地价格字段为人民币（沪B美元、深B港元），港股全部金额字段为港元。超过200行自动CSV；显式export_path也只返回文件及元信息。只输出所选列，MCP/CLI共用实现，绘图调用同一入口。

close_ifind_excel()为无参数MCP工具，CLI为`{"tool":"close_ifind_excel"}`，只关闭本包专用工作簿，保护其他用户工作簿；不另设打开或清空工具。导出规则声明Windows COM依赖并携带空白工作簿，不自动修改登录或用户配置。
