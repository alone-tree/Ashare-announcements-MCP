## 逐步验证通过的调用

以下是实际执行步骤的核心命令，完整等待、输出及关闭逻辑只在脚本维护。

```python
# 1. 创建专用 xlsx；避免以 COM 创建全新实例时插件加载状态不同。
from openpyxl import Workbook
book = Workbook()
book.save(workbook_path)

# 2. 系统正常打开。explorer 返回值不能替代后续 COM 连接检查。
import subprocess
subprocess.run(["explorer.exe", str(workbook_path)], timeout=10, check=False)

# 3. 连接已启动实例，不依赖自动生成的 COM 包装缓存。
import pythoncom, pywintypes
from win32com.client import dynamic
pythoncom.CoInitialize()
raw = pythoncom.GetActiveObject(pywintypes.IID("Excel.Application"))
excel = dynamic.Dispatch(raw.QueryInterface(pythoncom.IID_IDispatch))
# 等待 Workbooks 中出现 FullName 与本次路径一致的目标，再获取工作表。

# 4. 日期按文本存储，避免 datetime 时区转换；公式内日期也使用 ISO 字符串。
sheet.Range(f"A2:A{bottom}").NumberFormat = "@"
sheet.Range(f"A2:A{bottom}").Value2 = tuple((day,) for day in dates)
sheet.Range(f"B2:B{bottom}").Formula2 = tuple(
    (f'=@thsiFinD("ths_mv_back_test_stock","300502.SZ","{day}")',)
    for day in dates
)

# 5. 自然计算，不使用 CalculateFull；检查整块内容，不仅看 CalculationState。
rows = sheet.Range(f"A2:B{bottom}").Value2

# 6. 保存、关闭专用工作簿。仅退出本次启动且没有其他用户工作簿的 Excel。
workbook.Save()
workbook.Close(SaveChanges=False)
excel.Quit()
pythoncom.CoUninitialize()
```
